# hava-sicakligi-elektrik-talebi
Araştırma Yöntem ve Teknikleri dersi kapsamında Türkiye'de hava sıcaklığı ile elektrik talebi arasındaki ilişkinin incelenmesi.
## UML Diyagramları

Projenin tasarım sürecini açıklamak için üç UML diyagramı hazırlanmıştır.

- **Use Case:** Araştırmacının sistemde gerçekleştirdiği işlemleri ve veri kaynaklarını gösterir.
- **Activity:** Verilerin alınması, kontrol edilmesi, düzeltilmesi, analiz edilmesi ve grafiklerle sunulması sürecini gösterir.
- **Class:** Projede kullanılacak veri, işleme, analiz ve görselleştirme sınıflarını gösterir.

UML diyagramları bu depoda ayrı görsel dosyaları olarak paylaşılmıştır.
